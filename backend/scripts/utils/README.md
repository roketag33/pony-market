# Scripts Utilitaires

Scripts d'aide et d'automatisation divers.

## 📜 Scripts disponibles

### check-env.sh
Vérifie la configuration de l'environnement.
```bash
./check-env.sh
```

### setup-dev.sh
Configure l'environnement de développement.
```bash
./setup-dev.sh
```

## 🔍 Vérifications

- Variables d'environnement
- Dépendances système
- Versions des outils
- Permissions des fichiers
- Configuration Docker

## 📋 Configuration requise

- Docker
- Node.js 18+
- Yarn
- PostgreSQL client
- Redis client
