
# Scripts de Développement

Scripts utilisés pendant le développement de l'application.

## 📜 Scripts disponibles

### start.sh
Lance l'application en mode développement.
```bash
./start.sh
```

### clean.sh
Nettoie l'environnement de développement.
```bash
./clean.sh
```

## 🔧 Fonctionnalités

- Hot-reloading
- Gestion des permissions
- Nettoyage automatique
- Logs détaillés

## ⚠️ Précautions

- Exécutez toujours clean.sh avant de pull
- Vérifiez les permissions des fichiers
- Sauvegardez vos modifications locales
